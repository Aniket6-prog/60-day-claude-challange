🏥 Prior Authorization Story Simulator

An interactive, story-driven web application that explains the Prior Authorization (PA) process in a simple and engaging way. Users follow Rahul, a patient, and Priya, a healthcare operations specialist, through the complete PA journey—from diagnosis to insurance approval.

✨ Features
Interactive 8-scene healthcare story
Chat-style educational interface
Branching dialogue with user choices
Animated progress bar
Responsive design using Tailwind CSS
Vanilla JavaScript (no frameworks)
Single-file index.html
Accessibility-focused UI
Educational healthcare workflow simulation

----


🛠️ Tech Stack
HTML5
Tailwind CSS (CDN)
Vanilla JavaScript

----


🎯 Learning Objectives
Understand the Prior Authorization workflow
Learn how insurance reviews and appeals work
Practice modern DOM manipulation using createElement() and appendChild()
Explore interactive storytelling in web development

----

Disclaimer: This simulator is for educational purposes only. StarCare Health is used as an illustrative example. Actual prior authorization requirements vary by insurer, medication, diagnosis, and healthcare policy.
