Agent responsibilities

Planner

Turns the news event into claims, evidence requirements and a factuality rubric.

Executor

Uses supplied evidence to construct a professional blog draft without inventing facts.

Evaluator

Audits the current draft against every claim and returns a literal accuracy assessment.

Critic

Adversarially searches for unsupported, ambiguous, outdated or conflicting statements.

Improver

Receives the prior evaluation + critique and repairs the draft.

Memory Manager

Stores verified facts, unresolved claims and lessons for later rounds.

Safety Monitor

Prevents unsupported certainty and blocks automatic release when the evidence state is unsafe.

Final Reviewer

Performs the final release gate after a stop condition fires.

Stop-check logic

After every Evaluator call, checks happen in this exact order: 1) plateau — less than 2 percentage points of improvement for 2 straight rounds; 2) threshold — 100%; 3) hard iteration cap — safety fallback only. If no stop fires, Critic → Improver → Memory Manager runs and the improved draft returns to Evaluator.
