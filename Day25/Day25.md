# 🦈 AI Shark Tank Simulator

An interactive Shark Tank-inspired web application where users pitch startup ideas to AI-powered judges and receive detailed feedback, startup scores, funding recommendations, and investment decisions.

## ✨ Features

* AI Startup Pitch Submission
* Four AI Judges:

  * Venture Capitalist
  * Founder
  * Customer
  * Angel Investor
* Interactive Pitch Round
* Dynamic Judge Reactions
* Startup Evaluation (100-Point Scoring)
* Market Potential Analysis
* Innovation Assessment
* Business Model Evaluation
* Execution Review
* Investment Worthiness Score
* Investment Decision Engine
* Suggested Startup Valuation
* Recommended Funding Amount
* Confetti Celebration
* Download Pitch Report as PDF
* Leaderboard using LocalStorage
* Share Result Feature
* Modern Shark Tank Inspired UI
* Responsive Design
* Single-File HTML Application (No Backend Required)

## 🛠 Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* LocalStorage
* jsPDF
* Canvas Confetti

## 🚀 How to Run

1. Download the project.
2. Open `index.html` in any modern browser.
3. Enter your startup details.
4. Pitch your idea to the AI judges.
5. Answer their questions.
6. View your final score and investment decision.
7. Download your pitch report or share your results.
