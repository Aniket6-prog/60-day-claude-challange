# ⌨️ Typing Speed Studio

**A premium offline typing platform built with HTML, CSS, and Vanilla JavaScript.**

Typing Speed Studio is a modern single-page web application that delivers an engaging typing experience through multiple practice modes, live performance metrics, advanced analytics, and personalized feedback. Inspired by commercial typing platforms, it provides a polished interface while remaining completely offline and framework-free.

## ✨ Features

* ⌨️ Multiple Typing Modes

  * Time Mode (15, 30, 60, 120 seconds)
  * Word Count Mode (25, 50, 100, 250 words)
  * Quote Mode
  * Programming Mode
  * Custom Text Mode
  * Adaptive Mode
  * Focus Mode
  * Zen Mode

* 📊 Live Performance Metrics

  * Words Per Minute (WPM)
  * Raw WPM
  * Characters Per Minute (CPM)
  * Accuracy
  * Mistake Count
  * Current Streak
  * Completion Percentage
  * Remaining Time/Words
  * Real-time Progress Indicator

* 📈 Advanced Analytics Dashboard

  * WPM Progress Graph
  * Accuracy Graph
  * Consistency Score
  * Typing Rhythm
  * Error Heatmap
  * Character Analysis
  * Session Summary
  * Achievement Badges
  * Performance Insights
  * Personalized Improvement Suggestions

* 💾 Local Progress Tracking

  * Session History
  * Personal Bests
  * Improvement Timeline
  * Streak Tracking
  * Performance Comparison
  * Offline Data Storage

* 🎨 Premium User Experience

  * Dark Mode
  * Glassmorphism UI
  * Smooth Animations
  * Responsive Design
  * Theme Customization
  * Font Size Controls
  * Keyboard Shortcuts
  * Pause & Resume
  * Restart Options
  * Accessibility Support

## 🛠️ Built With

## 🚀 How to Run

1. Download or clone the repository.
2. Open the HTML file in any modern web browser.
3. Start practicing—no installation or internet connection required.

## 💡 Why This Project?

Typing Speed Studio demonstrates how modern frontend technologies can create a feature-rich, professional web application without external frameworks. It combines clean UI/UX, real-time performance calculations, local storage, interactive analytics, and responsive design into a seamless typing practice experience.
