# 🧠 Brain Dump → Action Planner

An AI-powered productivity dashboard that converts messy notes, brainstorming sessions, meeting transcripts, and voice memos into structured, actionable project plans.

Instead of manually organizing information, the application automatically generates an interactive dashboard that highlights summaries, action items, risks, questions, conflicts, and project insights.

---

# ✨ Features

## 📄 Smart Organization

Automatically structures information into:

* Summary
* Key Takeaways
* Action Items
* Open Questions
* Risks & Blockers
* Conflicts
* Additional Notes

---

## 📊 Interactive Dashboard

Modern dashboard inspired by:

* Notion
* ClickUp
* Linear
* Asana
* Airtable

Includes:

* Responsive layout
* Cards
* Tables
* Status badges
* Hover effects
* Collapsible sections
* Dashboard widgets

---

## ✅ Action Item Tracker

Displays tasks in an interactive table containing:

* Task
* Owner
* Deadline
* Status
* Priority

Supports:

* 🔴 High Priority
* 🟠 Medium Priority
* 🟢 Low Priority
* ⏳ Pending
* ✅ Completed

---

## 👥 Transcript Mode

When meeting transcripts are provided:

* Speaker Summary
* Decisions by Speaker
* Action Items by Speaker
* Attribution Notes

Ownership remains exactly as provided.

---

## 🔄 Merge Mode

Supports multiple note sources.

Features include:

* Source Tracking
* Duplicate Detection
* Conflict Review
* Source Information

Conflicts are displayed but never automatically resolved.
