# 🏥 Prior Authorization Workflow Simulator

An interactive, gamified simulator that demonstrates the complete **US Healthcare Prior Authorization (PA)** workflow using drag-and-drop interactions.

## 📌 Overview

This project provides a visual learning experience for understanding how healthcare providers, patients, and payers interact during the Prior Authorization process.

The simulator walks users through every stage, from medical necessity evaluation to final approval or denial, while providing educational explanations throughout the workflow.

---

## ✨ Features

* 🎮 Gamified drag-and-drop workflow
* 👨‍⚕️ Three workflow lanes:

  * Patient
  * Provider
  * Payer
* 📋 Multiple patient scenarios

  * Elective Surgery
  * MRI
  * Specialty Medication
  * Inpatient Admission
* 🩺 Medical Necessity Evaluation
* 📄 Prior Authorization Document Collection
* 📤 Submission to Payer
* 🔍 Payer Review Process
* ✅ Approval
* ⏳ Pend
* ❌ Denial
* 🔁 Appeal
* 🤝 Peer-to-Peer Review
* 📚 Educational explanations after each step
* 📈 Progress tracker
* 📅 Days elapsed counter
* ⚡ Efficiency score
* 🎉 Celebration animation on approval
* 📊 Workflow summary
* 🔄 Restart / New Patient functionality
* 📱 Fully responsive design

## 🚀 Getting Started

1. Download the project.
2. Open `index.html` in any modern web browser.
3. Select a patient scenario.
4. Drag the case through each workflow stage.
5. Complete the Prior Authorization process.

No installation required.
