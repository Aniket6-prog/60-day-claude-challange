System Architecture & Prompt Engineering Manual

1. Prompt Design Logic

The system prompt configures Claude to act as an uncompromising Senior Software Engineer using the Socratic method. Key features:

  • Strict Non-Spoiling Constraint: Forbids providing direct refactored code blocks, compelling the developer to think.
  • JSON Schema Enforcement: Forces output into a strict structure containing scores, granular metrics, finding items, and progressive hints.
  • Blunt & Professional Persona: Cuts out boilerplate conversational fluff ("Great job submitting code!").

2. UX Architecture

Designed tailored specifically for developer mental models:

  • Score Dial: Instant visual feedback on overall code health.
  • Progressive Hints: Scaffolds learning without revealing answers immediately.
  • Line-Level Findings: Categorizes architectural, algorithmic, and stylistic issues clearly.

3. Production Enhancements

Ways to extend this architecture:

  • WebAssembly Integration: Add client-side AST parsing prior to calling Claude for instant syntax validation.
  • Multi-Turn Memory: Store conversation thread state so developers can answer the Socratic question and get feedback on their attempt.
  • GitHub Webhook: Wire system prompt into PR automation pipelines.
