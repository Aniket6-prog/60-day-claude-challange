📌 Project Overview

Autonomous Agent Studio demonstrates how multiple AI agents collaborate throughout a software engineering lifecycle—from planning and execution to evaluation, safety checks, iterative improvement, and final review.

The dashboard provides an intuitive interface for understanding agent orchestration, making complex AI workflows easier to visualize and analyze.
