# 🚀 10-Day Capstone — Product Discovery to Deployed v1.0

> **AB Talks 60-Day Claude AI Challenge**

A 10-day product development challenge focused on taking a software idea from **problem discovery to a deployed v1.0 product** using an AI-assisted development workflow.

---

## 🎯 Goal

The objective of this capstone is to experience a complete software development lifecycle:

**Requirements → Design → Setup → Implementation → Testing → Deployment → Maintenance**

Rather than optimizing for the biggest possible project, the focus is on building a **small, useful, polished, and deployable product within 10 days**.

---

---

## 🔎 Day 1 — Product Discovery

Day 1 is intentionally focused on **discovery rather than coding**.

The key questions are:

* What problem are we solving?
* Who experiences this problem?
* How painful is the problem?
* What solutions already exist?
* What makes our solution useful?
* What is the smallest valuable MVP?
* What should explicitly remain outside v1.0?
* How will we measure success?

---

## 🧠 Product Discovery Principles

### 1. Solve a real problem

The product should address a meaningful user problem rather than simply demonstrate technology.

### 2. Start with the user

Features should be driven by user needs instead of technical possibilities.

### 3. Keep the MVP focused

Only features that contribute directly to the core value proposition belong in v1.0.

### 4. Protect against scope creep

Nice-to-have features will be documented for future versions rather than added during the 10-day build.

### 5. Ship something complete

A smaller polished product is more valuable than a large unfinished prototype.

## 🤖 AI-Assisted Development

Claude AI is being used as a:

* Product discovery partner
* Product mentor

* Development assistant

* Testing assistant
* Documentation assistant

The objective is not to blindly generate code, but to use AI throughout the software development lifecycle while maintaining human decision-making and validation.

---

## 🛡️ Scope Protection

The project follows one important rule:

> **Build the most impressive product that can realistically be completed and deployed within 10 days.**

Features that do not directly contribute to the core user value will be moved to future scope.

---

## 🏁 Definition of Done

The capstone will be considered successful when:

* ✅ The core user problem is clearly defined
* ✅ The MVP is fully implemented
* ✅ Core user workflows work end-to-end
* ✅ Major bugs are fixed
* ✅ The application is deployed
* ✅ The product is usable by real users
* ✅ Documentation is available
* ✅ The project can be demonstrated confidently
* ✅ v1.0 is ready to showcase
