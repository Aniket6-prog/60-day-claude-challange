Data Splitting, Validation & Generalization

The foundational principle of statistical machine learning is predicting outcomes on unseen data. Models must learn general underlying relationships rather than memorizing historical training inputs.

Real-World Analogy: Training a model on evaluation data is like giving a student the exact exam questions prior to a final test. High scores reflect rote memorization rather than actual subject comprehension.

Key Concepts

Dataset Split Proportion Primary Function
Train Set 60% - 80% Used directly by the optimization algorithm to update model weights.
Validation Set 10% - 20% Used for hyperparameter tuning and early stopping detection. Prevents data leakage.
Test Set 10% - 20% Held out entirely until final model selection. Evaluates true real-world performance.

K-Fold Cross-Validation

When working with limited datasets, fixed splits run the risk of sampling bias. K-Fold Cross-Validation mitigates this by partitioning data into $K$ equal subsets (folds), iteratively training on $K-1$ folds and evaluating on the remaining fold.

# Idiomatic K-Fold CV implementation in Python
from sklearn.model_selection import KFold
import numpy as np

X = np.array([[1, 2], [3, 4], [1, 2], [3, 4], [5, 6], [7, 8]])
kf = KFold(n_splits=3, shuffle=True, random_state=42)

for fold, (train_idx, val_idx) in enumerate(kf.split(X)):
    print(f"Fold {fold}: Train={train_idx}, Val={val_idx}")

Module 2

Optimization Mechanics: Gradient Descent

Training a machine learning model means minimizing a scalar **Loss Function** $L(\theta)$. Gradient Descent iteratively updates parameter vector $\theta$ in the opposite direction of the gradient vector $\nabla_\theta L(\theta)$.

$$\theta_{t+1} = \theta_t - \eta \cdot \nabla_\theta L(\theta_t)$$ Where $\eta$ represents the Learning Rate (step size parameter).

Optimization Variants

Batch Gradient Descent

Computes exact loss gradients across the entire dataset. Deterministic updates, but computationally prohibitive for large datasets.

Stochastic / Mini-Batch GD

Computes approximate gradients using small random data subsets (mini-batches). Adds stochastic variance that helps escape local minima.

Mathematical Formulations

$$\text{Precision} = \frac{TP}{TP + FP}$$

Quantifies prediction reliability. Crucial for spam filtering or fraud prevention where false alarms carry high operational costs.

$$\text{Recall (Sensitivity)} = \frac{TP}{TP + FN}$$

Quantifies detection coverage. Vital for medical diagnostics where missed positive cases carry severe consequences.

Module 4

Regression Metrics & Error Loss Surfaces

Evaluating continuous variable targets requires measuring absolute, squared, or proportional distances between actual targets ($y_i$) and predictions ($\hat{y}_i$).

Core Evaluation Metrics

Metric Equation Key Properties & Behavior
Mean Absolute Error (MAE) $$\frac{1}{n} \sum |y_i - \hat{y}_i|$$ Linear penalty scale. Robust against extreme outlier anomalies. Same units as original target variable.
Mean Squared Error (MSE) $$\frac{1}{n} \sum (y_i - \hat{y}_i)^2$$ Quadratic penalty scale. Heavily punishes large errors. Differentiable everywhere, making it ideal for direct gradient optimization.
Root MSE (RMSE) $$\sqrt{\text{MSE}}$$ Retains the heavy outlier penalty of MSE while converting loss dimensions back to original target units.
$R^2$ Coefficient $$1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$ Normalized scale ($-\infty$ to $1.0$). Measures the fraction of target variance explained by model features.

ML Evaluation Reference Cheatsheet

Metric Selection Guide

Problem Type Data Characteristics Recommended Metric
Balanced Classification Uniform class distribution Accuracy, ROC-AUC
Imbalanced Classification Rare positive classes (e.g. Fraud, Medical) PR-AUC, F1-Score, Balanced Accuracy
Regression Normal error distribution, no extreme outliers RMSE, $R^2$
Regression Data contains significant extreme outliers MAE, Huber Loss

Common Pitfalls to Avoid

  • Data Leakage: Performing feature normalization or imputation before splitting train/test datasets.
  • Evaluating on Training Data: Relying on training loss curves rather than validation loss to evaluate real-world generalization.
  • Ignoring Class Imbalance: Optimizing accuracy on imbalanced targets, leading to trivial majority-class classifiers.
