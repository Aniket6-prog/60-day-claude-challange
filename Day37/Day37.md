# 🧭 Task Compass

**Learn how work flows through real organizations.**

Task Compass is a single-file, offline web application that teaches how tasks move through organizations using an interactive management simulation. Instead of focusing on job titles, it helps users understand ownership, delegation, collaboration, escalation, and workflow thinking through realistic workplace scenarios.

## ✨ Features

* 🎮 Interactive management simulation
* 📌 Three progressive learning stages

  * **Stage 1:** Who Owns This?
  * **Stage 2:** Task Routing
  * **Stage 3:** Collaboration Challenge
* 🖱️ Drag-and-drop gameplay
* 💡 Detailed explanations after every decision
* 📈 Understanding dashboard with visual progress
* 📊 Radar/Bar chart showing learning across key workplace skills
* 📝 Personalized reflection and insights
* 🎉 Completion celebration with smooth animations
* 🌙 Premium dark UI with glassmorphism design
* 📱 Fully responsive
* 💻 Works completely offline

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript

## 🎯 Learning Objectives

Task Compass helps users develop practical workplace skills by exploring:

* Ownership and accountability
* Delegation
* Cross-functional collaboration
* Task routing and workflows
* Communication across teams
* Organizational thinking
* Decision-making in realistic work environments

## 🎮 Gameplay

### Stage 1 — Who Owns This?

Identify the primary owner of realistic workplace tasks and learn why they are responsible while understanding which teams typically assist.

### Stage 2 — Task Routing

Build the correct workflow by arranging roles in the order that work usually flows through an organization.

### Stage 3 — Collaboration Challenge

Solve larger business situations by assigning multiple departments, encouraging collaborative thinking instead of single-owner solutions.

3. No installation or internet connection required.

## 🌟 Why This Project?

Real workplace problems are rarely solved by one person alone. Task Compass demonstrates how responsibilities, communication, and collaboration come together to deliver successful outcomes, making organizational concepts engaging through interactive gameplay.
