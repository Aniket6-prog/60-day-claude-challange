# 📄 PDF Splitter & Merger

A modern, privacy-focused **PDF Splitter & Merger** built with **HTML, CSS, and Vanilla JavaScript**. All document processing happens entirely in the browser, ensuring that files never leave the user's device.

## ✨ Features

### PDF Splitter

* Upload PDF files
* Automatic page detection
* Visual page thumbnails
* Split by custom page ranges
* Split after selected pages
* Split every N pages
* Extract selected pages
* Multiple split operations in one session
* Input validation and preview

### PDF Merger

* Upload multiple PDF files
* Drag-and-drop file upload
* Drag-and-drop reordering
* File previews
* Total file and page count
* Merge summary
* One-click download

## 🎨 UI Highlights

* Modern professional interface
* Responsive design
* Dark mode
* Smooth animations
* Accessibility support

* Interactive feedback
