# 📰 Media Integrity Analyzer

An interactive educational web application that teaches **media literacy** through guided discovery and real-world inspired scenarios.

## 🎯 Overview

Media Integrity Analyzer helps users recognize misleading headlines, emotional manipulation, and persuasive writing techniques through interactive challenges instead of traditional quizzes.

Everything runs inside a **single HTML file** with **no external dependencies**, making it fully offline and easy to share.

## ✨ Features

* 🕵️ **Headline Detective**

  * Analyze fictional news headlines
  * Compare headlines with article content
  * Discover misleading wording
  * View Headline Accuracy Score
  * Learn how to write a fair headline

* 🎭 **Emotion Detector**

  * Explore emotionally charged social media posts
  * Identify emotional trigger words
  * Reveal manipulation techniques
  * Compare with a neutral rewrite

* 📊 **Live Media Integrity Metrics**

  * Headline Accuracy
  * Source Reliability
  * Emotional Manipulation
  * Audience Targeting

* 📈 **Media Integrity Dashboard**

  * Overall Media Integrity Score
  * Personalized learning summary
  * Biggest media red flag
  * Three practical media literacy habits
  * Replay with brand-new scenarios

## 🎓 Learning Goals

This project helps users:

* Think critically before sharing information
* Identify misleading headlines
* Recognize emotional manipulation
* Understand audience targeting
* Build healthy media consumption habits

## 🚀 How to Run

1. Download the HTML file.
2. Open it in any modern web browser.
3. Choose a theme.
4. Start exploring the interactive media literacy challenges.

No installation or internet connection required.
