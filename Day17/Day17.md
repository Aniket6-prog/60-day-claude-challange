# 🚗 Fuel Cost Analytics Dashboard

A modern, responsive **Fuel Cost Analytics Dashboard** built using **HTML, CSS, Vanilla JavaScript, and Pure SVG**.

The dashboard analyzes vehicle fuel datasets and presents meaningful insights into fuel efficiency, running costs, maintenance expenses, emissions, and E85 fuel economics through interactive visualizations.

---

## 📌 Features

### 🚘 Vehicle Summary

* Vehicle Model
* Fuel Type
* Vehicle Age
* Monthly Distance
* Personalized dashboard header

### 📊 KPI Cards

Displays:

* Your Fuel Cost per Kilometer
* E85 Cost per Kilometer
* E85 Premium vs Petrol
* Break-even Fuel Price
* Estimated Monthly Fuel Cost

---

## 📈 Analytics

### Cost Analysis

* Average Cost per Kilometer
* Fuel-wise comparison
* Monthly operating cost

### Environmental Analysis

* Average CO₂ Emissions per Kilometer
* Fuel-wise emission comparison

### Maintenance Analysis

* Maintenance Cost per Kilometer
* Vehicle age impact

### Refueling Analysis

* Average Refuel / Recharge Time

---

## 🚗 Vehicle Age Analysis

Vehicles are categorized into:

* New (0–2 Years)
* Mid-life (3–5 Years)
* Aged (6–9 Years)
* Old (10+ Years)

The dashboard highlights the selected vehicle age and compares:

* Cost per Kilometer
* Maintenance Cost per Kilometer

---

## 🌿 E85 Fuel Analysis

Special analysis includes:

* Pump Savings vs Petrol
* Running Cost Penalty
* Break-even Fuel Price
* Overall E85 Performance Score (/10)
