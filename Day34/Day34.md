# 🕵️ Marketing Detective

**Marketing Detective** is a premium interactive learning application that teaches marketing strategy through detective-style investigations.

Instead of reading marketing theory, users solve fictional marketing cases by analyzing campaign data, customer feedback, KPIs, and digital performance before identifying the real marketing mistake.

---

## ✨ Features

* 🕵️ Detective-themed learning experience
* 📂 Multiple fictional marketing investigation cases
* 📌 Interactive investigation board
* 🧩 Drag-and-drop evidence analysis
* 🎯 Solve the marketing mystery
* 📊 Campaign metrics visualization
* 💬 Customer and social media sentiment analysis
* 📈 Learning report with detailed explanations
* 🎨 Beautiful dark detective UI
* 📱 Responsive design
* 🔄 Random case generation for replayability
* 📄 Single-file HTML application

---

## 🎯 Learning Objectives

Users learn how to:

* Analyze marketing campaigns
* Identify strategic mistakes
* Evaluate KPIs

## 🎮 Gameplay

1. Receive a new marketing case
2. Explore the investigation board
3. Review campaign evidence
4. Organize clues
5. Identify the primary marketing mistake
6. Close the case
7. Review the learning report
8. Replay with another randomly selected case

1. Download the HTML file.
2. Open it in any modern web browser.
3. Start solving marketing mysteries.

No installation, backend, database, or additional dependencies required.

---

## 💡 Why This Project?

Traditional marketing education is often passive.

Marketing Detective transforms marketing analysis into an interactive detective experience where users learn by investigating, making decisions, and discovering the reasoning behind successful and unsuccessful campaigns.
